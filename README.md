# Codsoft-AI-Internship-task-2
Tic-Tac-Toe using Random AI and Minimax Algorithm.

## Task 2: Tic-Tac-Toe Game with AI
This is the second task of my Artificial Intelligence Internship at CodSoft.

## 📌 Project Overview
This project is a graphical Tic-Tac-Toe game built using Python’s tkinter library. The game allows a human player to compete against an AI opponent. Two versions of the AI are implemented:

🔹 Random AI – Makes random valid moves.

🔹 Minimax AI – A smart, unbeatable AI that always makes optimal decisions using the minimax algorithm.

## 🚀 Features
Interactive GUI using tkinter

Player vs AI gameplay

Two AI strategies (Random & Minimax)

Score tracking between player and AI

Reset button to restart the game

Real-time win/draw messages displayed (no popups)

## 🧠 What I Learned
GUI development with tkinter

How to manage game state and UI updates

Basics of game theory and decision-making in AI

Implementation of the minimax algorithm with recursion

Designing a smooth user experience with real-time feedback
